# «ԱՍՊԵՏԸ ԵՎ ՀԱՅՈՑ ԹԱԳԸ» (The Knight and the Armenian Crown)

2D Պատմական Էպոս և Պլատֆորմեր՝ նվիրված Հայաստանի 7 պատմական մայրաքաղաքներին։

![Game Preview](assets/yervandashat_bg.jpg)

## 📖 Սյուժե (Story)
Շատ դարեր առաջ, երբ Հայաստանը մեծ ու հզոր թագավորություն էր, արքունիքում պահվում էր **Հայոց Թագը**՝ երկրի միասնության խորհրդանիշը։ 
Մի մութ գիշեր Խավարի Ասպետը գողացավ թագը, կոտրեց այն 5 կտորի և թաքցրեց հինավուրց վայրերում։ Թագավորը կանչեց իր ամենաքաջ Ասպետին՝ հավատարիմ արքունական արծվի ուղեկցությամբ, որպեսզի նա վերականգնի թագի կտորներն ու երկրի միասնությունը։

## 🏰 7 Պատմական Քաղաքները (Levels)
1. **Երվանդաշատ** — Երվանդունիների հին մայրաքաղաքը (Արաքսի և Ախուրյանի հովիտ)
2. **Արտաշատ** — Արտաշես Ա-ի մայրաքաղաքը (Անտիկ ավերակներ, սյուներ և թակարդներ)
3. **Տիգրանակերտ** — Տիգրան Մեծի մեծ մայրաքաղաքը (Բազմահարկ պարիսպներ և պահակներ)
4. **Վաղարշապատ** — Արշակունիների կենտրոն (Հինավուրց տաճարներ և գաղտնի անցումներ)
5. **Դվին** — Միջնադարյան հարուստ մայրաքաղաք (Առևտրական շուկաներ և ամրոց)
6. **Արագած և Ամբերդ** — Լեռնային բերդ (Ձյունաբուք, քամի և ժայռեր)
7. **Անի** — 1001 եկեղեցիների քաղաք (Շքեղ ճարտարապետություն)
- **Վերջնամարտ (Boss)** — Խավարի Դղյակ և մարտ Խավարի Ասպետի դեմ։

## 🎮 Կառավարում (Controls)
- **Վազք / Շարժում՝** `A` / `D` կամ `←` / `→`
- **Ցատկ / Կրկնակի ցատկ՝** `Space` կամ `W` / `↑`
- **Սրի 3-հարվածանի Կոմբո / Օդային Պտույտ՝** `Z` կամ `J`
- **Արագ Դաշ (Dash) / Խուսանավում՝** `Shift` կամ `C`
- **Արքայական Վահան (Shield Block)՝** `X` կամ `K`
- **Արծվի Գրոհ (Eagle Dive Attack)՝** `E` կամ `Q`
- **Քարտեզ / Դադար՝** `Esc`

## 🚀 Տեղակայում Vercel-ում (Deployment on Vercel)
Այս նախագիծը պատրաստ է անմիջապես աշխատել Vercel-ում՝ առանց որևէ բարդ կոնֆիգուրացիայի.

4. Սեղմեք **Deploy**
